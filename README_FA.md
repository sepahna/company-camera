# Company Camera — Android Offline

نسخه اولیه پروژه اندروید بومی برای ساخت APK.

## امکانات پیاده‌سازی‌شده
- عکاسی با CameraX و دوربین عقب/جلو
- پرسیدن نام فایل بعد از هر عکس
- انتخاب دستی محل/پروژه با فیلد متنی
- ذخیره عکس‌ها در فضای اختصاصی اپلیکیشن، جدا از DCIM/Camera
- ثبت اطلاعات در Room/SQLite
- خروجی پشتیبان JSON شامل تصاویر به صورت Base64
- خروجی ZIP شامل backup.json و فایل‌های JPG
- بازیابی از JSON و ZIP
- اشتراک‌گذاری عکس از آرشیو

## ساخت APK
1. Android Studio را نصب کن.
2. این پوشه را با گزینه Open باز کن.
3. صبر کن Gradle Sync کامل شود.
4. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کن.
5. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

نیازمندی‌ها: JDK 17، Android SDK 35، اتصال اینترنت فقط برای دریافت وابستگی‌های Gradle در اولین Build.

## نکته مهم
- خود برنامه پس از نصب و دریافت وابستگی‌ها کاملاً آفلاین کار می‌کند.
- تصاویر در مسیر خصوصی اپلیکیشن زیر `Android/data/ir.mbarani.companycamera/files/Pictures/CompanyCamera/` قرار می‌گیرند و در Camera شخصی ادغام نمی‌شوند.
- حذف برنامه ممکن است فایل‌های خصوصی آن را حذف کند؛ قبل از حذف، ZIP یا JSON تهیه کن.
- JSON به دلیل Base64 شدن تصاویر می‌تواند بسیار حجیم شود؛ ZIP برای پشتیبان کامل مناسب‌تر است.
- این سورس یک اسکلت اجرایی اولیه است و در این محیط APK کامپایل و روی دستگاه واقعی آزمایش نشده است. قبل از استفاده عملیاتی، روی گوشی تست شود.


## ساخت APK با GitHub Actions (بدون Android Studio)

1. یک مخزن جدید در GitHub بساز (مثلاً `company-camera`).
2. تمام محتویات این پروژه ZIP را در ریشه مخزن قرار بده؛ پوشه `.github` را هم همراهش آپلود کن.
3. در GitHub وارد تب **Actions** شو.
4. گردش‌کار **Build Company Camera APK** را انتخاب کن.
5. روی **Run workflow** و سپس دکمه سبز **Run workflow** بزن.
6. پس از پایان موفق اجرا، وارد همان اجرای workflow شو.
7. در پایین صفحه، از بخش **Artifacts** فایل `company-camera-debug-apk` را دانلود کن.
8. ZIP دانلودشده را باز کن؛ فایل `app-debug.apk` داخل آن است. آن را به گوشی منتقل و نصب کن.

با هر Push روی شاخه main/master که فایل‌های پروژه را تغییر دهد نیز Build اجرا می‌شود.

### نکته
- GitHub Actions برای ساخت APK به Android Studio روی کامپیوتر تو نیاز ندارد.
- اولین Build ممکن است چند دقیقه طول بکشد تا Gradle وابستگی‌ها را دانلود کند.
- این خروجی Debug است و برای نصب آزمایشی روی گوشی مناسب است؛ برای انتشار عمومی باید نسخه Release امضاشده ساخته شود.
- سورس فعلی در این محیط روی دستگاه اندرویدی آزمایش نشده؛ اگر Build خطا داد، متن کامل خطای GitHub Actions را بفرست تا اصلاح کنیم.


## نسخه اصلاح‌شده GitHub Actions
در این بسته، نصب SDK به دو بخش تقسیم شده است: `platform-tools` در تنظیمات اکشن و `platforms;android-35` و `build-tools;35.0.0` با فراخوانی مستقل `sdkmanager`. این تغییر از ارسال چند نام پکیج به‌صورت یک رشته واحد جلوگیری می‌کند.

برای استفاده، محتویات پوشه `CompanyCameraAndroid` را در ریشه مخزن GitHub جایگزین کنید و پوشه `.github/workflows` را نیز حفظ کنید. سپس از Actions گردش کار Build Company Camera APK را اجرا کنید.

توجه: این بسته هنوز در GitHub Actions اجرا و روی گوشی واقعی آزمایش نشده است؛ موفقیت Build تا زمان اجرای واقعی قابل تضمین نیست.
